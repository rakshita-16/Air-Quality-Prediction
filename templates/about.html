About This Project

An end-to-end machine learning application for predicting Air Quality Index (AQI) in real time.

Machine Learning Models

  • Random Forest Regressor — predicts the numeric AQI score
  • Random Forest Classifier — categorises air quality (Good → Hazardous)
  • Both models are trained on 5,000 synthetic samples covering diverse pollution scenarios
  • Features are standardised with StandardScaler before training

Tech Stack

Python 3.x Flask 2.3 scikit-learn NumPy Pandas Matplotlib Seaborn HTML5 / CSS3 JavaScript (ES6+)

How to Run

  1. Install dependencies: pip install -r requirements.txt
  2. Train models: python train_model.py
  3. Start the app: python app.py
  4. Open http://127.0.0.1:5000 in your browser
